# How AI really works

Three quick games for your phone. Each one shows a different insight about how AI actually generates text. These games were generated by Claude Code based on human ideas ;). 
Game 1 demonstrates tokenisation. Game 2 demonstrates how a next-token prediction machine is turned into a chatbot. Game 3 demonstrates how LLMs are taught which answers to pick. 

Play them here: https://kunkelalexander.github.io/te-how-does-ai-work/
